# Irfan Raza Portfolio — V8 Long Format

Static HTML/CSS/JS website prepared for GitHub Pages. The provided YouTube video `https://youtu.be/043qBi8qw-Q` is embedded in the dedicated **Long-Form Editing** section, with an external watch link and responsive 16:9 player.

## Deploy to GitHub Pages
1. Extract this ZIP.
2. Upload the contents of this folder (not the ZIP itself) to the root of your repository.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.

The YouTube video is streamed from YouTube; it is not downloaded into the repository. Google Fonts and the YouTube thumbnail also load from their public URLs.
